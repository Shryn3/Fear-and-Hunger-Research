# Warding sigil

**Soul:** [[Changeling soul]]

**Learned by (per wiki list):** [[Marina]]

| | |
|---|---|
| **Description** | Draw a warding sigil on the ground to fend off malice and creatures with ill intent. Originally created by the Virgin Mages of the Eastern Sanctuaries. |
| **Effect** | Allows you to create a sigil on the tile you're currently standing on which will block enemies from walking on that tile, expires on map transition. |
| **Cost** | 10 Mind |
