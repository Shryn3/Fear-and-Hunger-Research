# Counter stance

**Soul:** [[Tainted soul]]

**Learned by (per wiki list):** [[Marcoh]]

| | |
|---|---|
| **Description** | Stay alert for enemy attacks and counter when possible. |
| **Effect** | Applies [Counter](https://fearandhunger.wiki.gg/wiki/Status_Effects_F%26H2#Player_Buffs-0) status. *Counter stance* does not work with the [Lugr Pistol](https://fearandhunger.wiki.gg/wiki/Lugr_Pistol), [Rifle .303 Mk I](https://fearandhunger.wiki.gg/wiki/Rifle_.303_Mk_I) or [12-gauge Trenchgun](https://fearandhunger.wiki.gg/wiki/12-gauge_Trenchgun), but works with the [Bayonet](https://fearandhunger.wiki.gg/wiki/Bayonet) |
| **Cost** | Free |
