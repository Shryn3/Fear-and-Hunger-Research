# Medicinal

**Soul:** [[Blank soul]]

**Learned by (per wiki list):** [[Daan]]

| | |
|---|---|
| **Description** | Sacrifice harvested organs to Vitruvia, the architect of the human body. A sacrifice will cure a corresponding status ailment. Medicinal is based on the law where every action has an equal reaction. |
| **Effect** | Gives an option to use harvested organs to cure different status effects for 10 mind (Fracture requires only 7 mind): / Liver ([Toxic](https://fearandhunger.wiki.gg/wiki/Status_Effects_F%26H2#Player_Debuffs-0)) / Kidney ([Poisoned](https://fearandhunger.wiki.gg/wiki/Status_Effects_F%26H2#Player_Debuffs-0)) / Eye ([Blindness](https://fearandhunger.wiki.gg/wiki/Status_Effects_F%26H2#Player_Debuffs-0)) / Heart ([Bleeding](https://fearandhunger.wiki.gg/wiki/Status_Effects_F%26H2#Player_Debuffs-0)) / Parathyroid glands ([Fracture](https://fearandhunger.wiki.gg/wiki/Status_Effects_F%26H2#Player_Debuffs-0)) / Thymus ([Infected arm/leg](https://fearandhunger.wiki.gg/wiki/Status_Effects_F%26H2#Player_Debuffs-0)) |
| **Cost** | Passive |
