# 5e - Index

A separate section: 5th edition (2024 rules) comparables for the Fear & Hunger soul skills, so each soul type can be turned into a 5e-style package. It contains no links to or from the rest of the vault. Fear & Hunger skill text is repeated here only as plain quotes with their wiki URL.

> [!warning] Source limit
> Rules text comes only from the free System Reference Document 5.2.1, the officially published subset of the 2024 core rules. Spells, feats and class features that are not in the SRD are not quoted, because they could not be read from an official free source. The author's comparison notes are labelled [DESIGN NOTE] and the suggested soul shapes [DESIGN SUGGESTION]; neither is book text.

## How to read a soul note
- Each skill is a collapsible card with the wiki's text, then comparables with a fit rating.
- 🟢 Close: same basic effect, numbers differ. 🟡 Partial: overlaps in part. ⚪ Loose: shares an idea only. none: nothing citable in the SRD.
- Click a comparable to see the quoted SRD passage and page.
